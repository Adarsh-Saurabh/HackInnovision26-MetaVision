# MetaVision / Second Brain (HackInnovision 2026, Track B)

At the start of every session, before doing anything else:

1. Read the "Resume here" section of all three files in `workDone/` (`ujjwal.md`, `adarsh.md`, `vaibhav.md`). Each teammate has their own file.
2. Work out who you are working with: match `git config user.name` to one of the names; if unset or unclear, ask. Their "Next action" is where to start.
3. For team-wide P0 status, trust the snapshot with the newest `_Updated:` time, and check the others for anything newer per row.
4. Then read only the sections of `temp/PROJECT_B_BLUEPRINT.md` those snapshots cite.

At the end of a session the user runs `/update-work-done`, which edits only their own `workDone/<name>.md`. Do not run it unprompted.

Setup, Git workflow, and team conventions: `setup.md`.
